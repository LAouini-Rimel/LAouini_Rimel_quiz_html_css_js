# Quiz HTML/CSS/JavaScript

Un projet de quiz interactif développé avec HTML, CSS et JavaScript.

## 🚀 Fonctionnalités
- Questions à choix multiples
- Timer/compte à rebours
- Calcul du score en temps réel
- Interface responsive et moderne
- Feedback immédiat pour chaque réponse
